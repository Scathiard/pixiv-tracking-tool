# PixivTracker v0.2.5

- 流式多页作品只在开始处显示标题、作者与分级，后续页保留页码和放大操作。
- 流式图片按自然宽高比例展开，去掉固定高度造成的上下黑边；长图、横图和手机窄屏都会自适应。

直接使用现有图库，无需转换，默认端口 1919。退出旧版托盘程序后，打开 `D:\PixivTracker\PixivTracker_v0.2.5.exe`。
