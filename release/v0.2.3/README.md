# PixivTracker v0.2.3

这次调整作品角标与收藏操作：

- 图库、画师近期作品、详情和流式显示 R-18／R-18G，使用已有分级资料。
- 详情页收藏移到全部图片下方、完整简介之前。
- 收藏提交和正常核对不再弹提示框；按钮立即显示核对中，失败仍会反馈，只有主站回读确认才改变收藏事实。

直接沿用 `D:\PixivTracker` 的现有图库，默认端口 1919，与 v0.2.2 使用相同的数据结构，无需搬库或转换。若旧版正在运行，先从托盘退出，再打开同目录的 `PixivTracker_v0.2.3.exe`；旧包保留。

本地交付，未公开发布。用户体验与实体手机仍由用户验收；本次没有操作真实 Pixiv 收藏、检查或下载，也没有改变登录配置和自动检查设置。设置统计 BUG-054 等未包含在本轮修订中。

源码、验证和文件散列见[交付记录](../../docs/审查/2026-09-28-v0.2.3界面修订.md)、[SHA256SUMS.txt](SHA256SUMS.txt)和[构建记录](build-manifest.json)。
