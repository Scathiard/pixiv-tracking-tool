# PixivTracker v0.2.4

图库、详情、流式和整理面板的收藏按钮统一只显示心形，去掉文字、时间和额外标记；详情按钮仍在作品图片下方。主站确认收藏后才显示实心红心，同步期间防重复点击，失败仍有反馈。

直接使用现有图库，无需转换，默认端口 1919。若旧版正在运行，先从托盘退出，再打开 `D:\PixivTracker\PixivTracker_v0.2.4.exe`。

这是本地交付，未公开发布；旧包、图库、配置和令牌保留。验证范围及文件散列见[交付记录](../../docs/审查/2026-09-28-v0.2.4纯红心按钮.md)、[构建记录](build-manifest.json)和[SHA256SUMS.txt](SHA256SUMS.txt)。
