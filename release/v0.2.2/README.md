# PixivTracker v0.2.2

v0.2.2 是当前唯一主线和日常版本，R4 样稿已落实为正式页面。EXE 已通过隔离检查，并于 2026-09-28 在 `D:\PixivTracker` 接入真实图库离线启用。仓库根 `app/` 是当前源码；旧版本仅作历史保留。真实 Pixiv、实体手机和用户体验尚未验收，亦未公开发布。EXE 不内置账号令牌、运行配置或用户图库。

## 这版改了什么

- 恢复 Pixiv 蓝及清晰的卡片层级，完成图库、详情、流式、画师和设置页。
- 点图直接进详情，简介完整显示；Logo、返回与两种阅览分别记住位置。
- 画师支持网格/横列及最近作品横拖；明暗主题柔和切换且可连续点击。
- 收藏先显示同步中，主站回读确认后才改变红心；离线、失败和待确认如实显示。
- 仅有任务时出现进度；结果保留在历史中，结束不会刷新阅读页。
- 大图库与超长作品使用有界窗口，缩略图独立于原件。

## 启用状态

默认端口 **1919**。现有 `D:\PixivTracker` 已升级，此前以 `PixivTracker_v0.2.2.exe --offline` 启用，自动检查保持暂停；15,244 件作品、83 位画师与原媒体路径保留。主线切换时程序已关闭、1919 无监听，本轮不重启。升级前备份位于 `D:\PixivTracker-v022-backup\20260928-104556`，原库和旧包保留供回退，具体见 [真实接入记录](../../docs/审查/2026-09-28-v0.2.2真实图库接入.md)。

已知 BUG-054：设置页“已下载页数”只计已核验的原图资产，会少算旧存档；不代表原文件丢失。当前版本的升级入口仍是开发工具，后续程序与图库兼容升级必须同版交付。

若后续获批真实账号测试，只使用实施记录中列出的三件样本；收藏测试须先核对初始未收藏，完成收藏/取消后恢复原状。日常自动检查与最终体验验收另行记录。
