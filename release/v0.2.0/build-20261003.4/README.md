# PixivTracker 0.2.0 · 构建 20261003.4

本轮 20 项计划的完整候选，已通过源码、浏览器及 EXE 隔离验证，尚未公开发布或通过用户体验验收。

## 本轮变化

- 后台维护可暂停、继续并在重启后恢复，小操作能够及时执行；重复启动回到已有程序。
- 作品内容或资料改变时保留历史版本，详情可以切换；新版未齐仍保留可看的旧档。
- 流式提供顺序／随机、上一件／下一件；手机单击放大、双击添加收藏，放大层双击调倍率。
- 画师网格完整三张，列表按相同尺寸显示更多；添加前预览身份，可单独检查新作。
- 设置恢复分钟／小时周期，来源无法访问清单独立分页；筛选完整可达，统计、详情和图片缓存修订。

## 启用与旧图库

本文件夹仅含程序、散列及交付记录，没有复制真实图库、配置或令牌。`D:\PixivTracker` 的日常程序与图库尚未改变。

首次接入 0001／0002 图库时需要升级至 0003。程序先显示确认页，确认后创建备份、转换并核验，再启用；原媒体路径保留。备份、候选和恢复记录保存在实际数据目录的 `upgrade/日期-随机标识/`，旧 EXE 应保留。升级后已经产生新写入时，禁止直接用旧快照覆盖新记录。

本轮真实启用需用户确认具体范围；随后先停止旧实例，备份、放置新版并离线核验，保证同一图库只有一个写入者。默认端口仍为 1919。`--offline` 可用于本地核验，不启动 Pixiv 登录或自动检查。
