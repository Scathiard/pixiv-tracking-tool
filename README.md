# PixivTracker

本地优先的 Pixiv 存档与阅览工具。喜爱画师的原件、动图原包和播放时序保存在本机；电脑和同一局域网的手机都可阅读。

**当前主线为 0.2.0 · 内部构建 20261003.3（取消最后停留位置）。** 公开版本暂锁 0.2.0，内部改动以构建号区分；版本号更替以获批公开发布为准。仓库根目录的 `app/` 是当前源码，`D:\PixivTracker` 是实际运行目录。2026-09-28 接入时有 15,244 件作品、83 位画师；旧版本和旧 `master` 仅供历史追溯。主线认定不等于全部功能通过用户验收，也不代表公开发布。

## 使用

- Windows EXE 默认使用自身目录下的 `data/` 与 `images/`，默认端口 **1919**。
- 在电脑访问 `http://localhost:1919`，手机访问 `http://电脑的局域网地址:1919`。
- 本地浏览无需登录；在设置中连接 Pixiv 后，才可检查、下载和同步收藏。
- 日常入口是 `D:\PixivTracker\PixivTracker_v0.2.0_build20261003.3.exe`；若旧版正在运行，先从托盘退出再打开新版，并刷新原有网页。`--offline` 启动不连接 Pixiv、不启动自动检查，仍可生成本地缩略图。
- 本构建延续此前 v0.2.5 实现，与 v0.2.2～v0.2.5 直接共用原图库，无需转换；不是退回历史 0.2.0 程序。更早的 0001 结构仍需先备份和转换为 0002，普通启动不会自动改写旧结构。

## 当前功能

- 图库：本地缩略图与可见轻量动图预览（滚动暂停、停止后恢复）、侧栏搜索、筛选抽屉、排序、连续滚动与页码模式；侧栏可收起，手机使用菜单抽屉，首页可检查新作品。
- 详情：点击作品进入，上下方向键逐张定位当前作品，左右与底栏按钮切作品；底栏包含唯一收藏红心，电脑文字单行、手机使用箭头；简介不折叠。
- 流式：所有页面连续展开，重新进入从当前范围开头开始，底栏收藏在“跳过作品”左侧。
- 导航与放大：不再记住上次停留位置，重新进入首页、点击 Logo 或侧栏“作品”回到首屏，保留筛选／排序；独立缩放与平移层关闭后仍回到本次进入位置。
- 画师：独立核对主站主页，确认不存在才标红头像；网格／横列使用同尺寸的最近作品。全部作品页显示会随滚动离屏的画师资料与主站链接。
- 设置：用“检查并补齐图库”统一核验、刷新资料、回读收藏及补齐缺件；“原作已不存在”按作品／画师列出来源问题和具体本地缺项。保留登录、暂停后续检查、日志、端口与存储、主题和浏览偏好。
- 收藏：点击后立即仅显示实心红心至少三秒，查询有结论后恢复同账号最近核实的状态；这段点击反馈不修改收藏事实，失败或待确认保留最近结果，旧缓存显示核实时间。
- 阅读信息：点击画师直接查看其全部本地作品；标签旁显示并缓存主站中文译名，没有译名只显示原标签。旧作品可用设置中的“检查并补齐图库”或单件“整理作品 → 刷新作品信息”补取译名；单件刷新不重下载图片，不引入机翻。
- 存档：检查、下载与本地处理并行，新作发现后及时保存，日常检查保持轻量；设置手动维护完整核验已有存档，并补缺页、坏文件、动图原包／时序和预览，已完整原件不重下载。来源问题不影响已有存档，仅在设置及画师管理中显示；404 和私密不能证明删除，未确认项单独列出。失败与重启可恢复。
