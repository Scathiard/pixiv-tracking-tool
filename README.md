# PixivTracker

本地优先的 Pixiv 存档与阅览工具。喜爱画师的原件、动图原包和播放时序保存在本机；电脑和同一局域网的手机都可阅读。

**当前交付为 0.2.0 · 内部构建 20261004.2，已在 `D:\PixivTracker` 正常启用。** [新版 EXE](release/v0.2.0/build-20261004.2/PixivTracker_v0.2.0_build20261004.2.exe) 修复大维护任务与本地浏览争用：任务查询按索引定位，图库只加载当前窗口，设置减少重复读取。原维护已恢复推进，真实图库、图片、设置与进度复测通过；见[修复与验证](docs/审查/2026-10-04-整夜维护与本地浏览阻塞修复.md)。原有登录、自动检查和文件保留；整夜稳定性、实体手机、账号专项与用户体验尚待验收，未公开发布。

## 使用

- Windows EXE 默认使用自身目录下的 `data/` 与 `images/`，默认端口 **1919**。
- 在电脑访问 `http://localhost:1919`，手机访问 `http://电脑的局域网地址:1919`。
- 本地浏览无需登录；在设置中连接 Pixiv 后，才可检查、下载和同步收藏。
- 日常入口是 `D:\PixivTracker\PixivTracker_v0.2.0_build20261004.2.exe`；原有网页刷新即可。平常直接双击 EXE 正常启动，复用现有登录，沿用每 360 分钟检查一次的设置，原有待办继续处理。
- 程序支持作品历史版本。首次接入 0001／0002 旧图库时显示升级确认页，确认后备份、转换、核验并启用 0003 结构，原有图片路径保留。本机真实升级已完成；本包只为当前结构补充任务查询索引，先一致性备份再建立，重复启动不再备份或转换。旧 EXE、备份与候选保留，已有新版写入时不会自动拿旧快照覆盖。

## 当前功能

- 图库：本地缩略图与可见轻量动图预览（滚动暂停、停止后恢复）、侧栏搜索、筛选抽屉、排序、连续滚动与页码模式；侧栏可收起，手机使用菜单抽屉，首页可检查新作品。
- 详情：点击作品进入，上下方向键逐张定位当前作品，左右与底栏按钮切作品；底栏包含唯一收藏红心，电脑文字单行、手机使用箭头；简介不折叠。
- 流式：全部页面连续展开，可切换顺序／随机；随机一轮内不重复，上一件沿本次顺序返回。底栏提供上一件、红心和下一件；手机单击图片放大，双击添加收藏，放大层双击调整倍率。
- 导航与放大：不再记住上次停留位置，重新进入首页、点击 Logo 或侧栏“作品”回到首屏，保留筛选／排序；独立缩放与平移层关闭后仍回到本次进入位置。
- 画师：添加前预览身份，支持名字、ID 或主页地址查询；单画师检查可查看上次结果。网格完整显示三张最近作品，横列按相同尺寸铺开更多；有效的主页无法访问事实标红头像，全部作品页保留随滚动离屏的资料与主站链接。
- 设置：用“检查并补齐图库”统一核验、批量核对画师主页、刷新资料、回读收藏及补齐缺件；新任务先核对范围内画师，包含停止追踪和零作品画师，旧任务保留进度。支持暂停、继续和重启恢复；“主站已无法访问”在独立分页清单中显示来源与本地缺项。保留登录、自动检查周期及暂停、日志、手机地址、端口与存储、主题和浏览偏好。
- 收藏：点击后立即仅显示实心红心至少三秒，查询有结论后恢复同账号最近核实的状态；这段点击反馈不修改收藏事实，失败或待确认保留最近结果，旧缓存显示核实时间。
- 阅读信息：点击画师直接查看其全部本地作品；标签旁显示并缓存主站中文译名，没有译名只显示原标签。旧作品可用设置中的“检查并补齐图库”或单件“整理作品 → 刷新作品信息”补取译名；单件刷新不重下载图片，不引入机翻。
- 存档：检查、下载与本地处理并行，新作及时保存，日常检查保持轻量；手动维护核验并补缺页、坏文件、动图原包／时序和预览。内容或资料变化保存新版本，详情可选历史版本，新版未齐时仍显示可看的旧档；单件可主动重新比对原图。来源问题只在设置及画师管理显示，暂时网络故障不判为来源无法访问，已有本地文件继续可看。
