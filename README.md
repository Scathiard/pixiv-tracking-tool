# PixivTracker

本地优先的 Pixiv 存档与阅览工具。喜爱画师的原件、动图原包和播放时序保存在本机；电脑和同一局域网的手机都可阅读。

**当前主线为 0.2.0 · 内部构建 20261002.1（快速滚动故障恢复）。** 公开版本暂锁 0.2.0，内部改动以构建号区分；版本号更替以获批公开发布为准。 仓库根目录的 `app/` 是当前源码，`D:\PixivTracker` 是实际运行目录。2026-09-28 已接入原图库的 15,244 件作品、83 位画师；旧版本和旧 `master` 仅供历史追溯。主线认定不等于全部功能通过用户验收，也不代表公开发布。

## 使用

- Windows EXE 默认使用自身目录下的 `data/` 与 `images/`，默认端口 **1919**。
- 在电脑访问 `http://localhost:1919`，手机访问 `http://电脑的局域网地址:1919`。
- 本地浏览无需登录；在设置中连接 Pixiv 后，才可检查、下载和同步收藏。
- 日常入口是 `D:\PixivTracker\PixivTracker_v0.2.0_build20261002.1.exe`；若旧版正在运行，先从托盘退出再打开新版。`--offline` 启动不连接 Pixiv、不启动自动检查，仍可生成本地缩略图。
- 本构建延续此前 v0.2.5 实现，与 v0.2.2～v0.2.5 直接共用原图库，无需转换；不是退回历史 0.2.0 程序。更早的 0001 结构仍需先备份和转换为 0002，普通启动不会自动改写旧结构。

## 当前功能

- 图库：本地缩略图与可见轻量动图预览（滚动暂停、停止后恢复）、侧栏搜索、筛选抽屉、排序、连续滚动与页码模式；侧栏可收起，手机使用菜单抽屉，首页可检查新作品。
- 详情：点击作品进入，上下读完整多页，简介不折叠；按钮、方向键与手机手势切作品。
- 流式：独立阅读位置，所有页面连续展开，底栏收藏在“跳过作品”左侧。
- 放大：独立缩放与平移层，关闭后回到进入位置；Logo 返回图库并恢复位置。
- 画师：主站主页链接、本地头像与简介、最近作品、网格／横列呈现、追踪与存档管理。
- 设置：登录、暂停后续自动检查、只读处理日志、端口与存储、明暗主题和浏览偏好。
- 收藏：红心表示同账号最近核实的 Pixiv 收藏；写入后等待回读，失败或待确认不会冒充成功，旧缓存显示核实时间。
- 存档：检查、下载与本地处理并行，新作发现后立即排入保存；日常不反复核验已确认旧图，全量核验由设置手动启动，整件原件与派生分别显示。失败与重启可恢复；手动补下载覆盖范围内可补的旧动图原包，无法访问项单独说明并保留 GIF；自动检查不顺带补旧原包。主站不可获取不影响已有存档；缺项说明原因，需要核对时停止反复重试，404 不直接判作删稿。
