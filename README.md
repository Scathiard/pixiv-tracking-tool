# Pixiv Tracking Tool

自动监控 Pixiv 特别关注画师的新作品，无条件下载全部插画/漫画/动图，从此不再痛失最喜爱的画师的被删除作品，在有大量关注的情况下也不会错过特别关注画师的新作。

## 快速开始

1. 双击 `PixivTracker_vX.X.X.exe` 启动（启动后无窗口，图标在系统托盘区）
2. 首次启动会自动弹出浏览器，登录你的 Pixiv 账号完成授权
3. 浏览器登录成功后确认授权
4. 打开 http://localhost:1919 进入 Web 界面
5. 同一局域网内的手机可直接访问 `http://电脑IPv4:1919` 或 `http://[电脑IPv6]:1919`，不需要配对或再次登录；可用地址会显示在设置页

## 功能

- **画师管理** — 搜索/Pixiv ID 添加特别关注，自动拉取全部作品并下载，支持暂停/恢复/刷新
- **画廊浏览** — 缩略图网格，画师/类型/期间/Tag 多维度筛选，无限滚动或页码翻页
- **收藏同步** — 一键收藏/取消收藏（同步 Pixiv 主站），校验补全作品信息（补拉 caption、标记缺失文件）
- **筛选面板** — ☰ 浮动面板，手风琴式 section：画师、类型、投稿期间、Tag、显示选项
- **作品详情** — 原图查看、画师简介（caption）、前后导航（键盘←→ / 触屏滑动）、点击 tag 跳转筛选
- **隐藏/删除** — 隐藏作品（虚线边框+半透明）、永久删除本地文件；永久删除记录会阻止后续同步把作品重新下载回来
- **Ugoira 转 GIF** — 动图自动转换
- **数据目录迁移** — 设置页一键迁移存储位置

## 使用方法

### 添加画师

- 进入「画师管理」页面
- 搜索画师名称或直接输入 Pixiv 用户 ID（如 `12345678`）
- 点击「特别关注」，系统会自动拉取该画师的全部已有作品并下载

### 浏览作品

- 首页显示全部已下载作品，可按画师、类型、投稿期间和 Tag 筛选
- 筛选面板：点击 ☰ 按钮打开，所有筛选条件 AJAX 即时生效
- 默认无限滚动加载更多作品，可在设置切换为页码翻页
- 点击作品缩略图查看详情

### 收藏

- 详情页右下角心形按钮、画廊卡片 hover 角标
- 设置页可一键校验并补全所有已有作品的信息（简介 caption、缺失文件标记等）

### 定时检查

- 默认每 6 小时自动检查关注画师是否有新作品
- 可在「设置」页面手动触发检查

## 数据存储

数据库、认证 token 和作品图片存放在数据目录下，默认数据目录就是 EXE 所在目录：

```
数据目录/
├── data/              数据库、认证 token 和永久删除清单
├── images/            下载的作品图片
│   ├── 画师名 12345/
│   └── 画师名 67890/
```

`.env` 配置文件始终放在 EXE 同目录，不随数据目录迁移。

在「设置」页面可修改数据存储目录。目标必须为空；程序会复制 SQLite 一致快照与图片并校验，全部成功后才切换。旧目录会保留，不会自动删除；迁移失败时继续使用旧目录。

## 配置文件 (.env)

```env
# IPv4 与 IPv6 共用端口
PORT=1919

# 数据存储目录（默认 . 即程序所在目录）
# DATA_ROOT=.

# 定时检查间隔
CHECK_INTERVAL_HOURS=6
```

## 系统要求

- Windows 10+
- 能访问 Pixiv 的网络环境

## 注意事项

- 作品下载到本地后，即使画师在 Pixiv 上删除作品，本地仍有备份
- Ugoira（动图）会自动转换为 GIF 格式
- 多页作品（漫画）会下载所有页面
- Web 服务默认同时监听 IPv4 与 IPv6，但只接受本机活动网卡所属局域网的来源；不会自动修改 Windows 防火墙
- 不设登录或配对意味着同一局域网中的其他设备也能查看和操作这个工具。不要把 `1919` 端口转发到公网，也不要直接放到公开反向代理后
