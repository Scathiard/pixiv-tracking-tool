# HTML 样稿交互复审

日期：2026-09-27。范围：R-056 的离线 HTML 样稿；旧版与本次候选原文、截图和检查结果均保留在[同批证据](证据/2026-09-27-HTML样稿交互复审/README.md)。

**结论：此前样稿过于关注页面上有没有控件，没有充分检查用户在什么时刻需要它、点下去后会发生什么。** “跳过这件”出现在作品末尾，是明显的用途与位置错配；完整走查还发现来源范围、手机入口和状态恢复的问题。本轮已在样稿中修正，不据此宣布正式程序或视觉验收通过。

可直接打开：[最新 HTML 样稿 R4](证据/2026-09-27-HTML样稿交互复审/prototype-r4.html)。日常评审入口仍为项目 .devtools 下的 ui-prototype-20260927.html，两份内容一致；[首轮候选](证据/2026-09-27-HTML样稿交互复审/prototype.html)作为历史证据保留。

**用户反馈修订 R2：** 流式收藏红心移到跳过左侧，滚动与跳过后跟随当前作品；详情简介改为直接显示的文本区，完全去掉折叠，任务阶段等其他展开功能保留。桌面、390px、320px 的位置与操作检查通过，见[R2 验证](证据/2026-09-27-HTML样稿交互复审/r2-checks.json)；正式程序未修改。

**用户反馈修订 R3：** 设置页深浅主题加入 280ms 完整配色揭示，避免中段低对比灰字灰底；桌面与 390px 双向中段、快速反向、减少动画、位置与状态保留及持久化检查通过，见[R3 验证](证据/2026-09-27-HTML样稿交互复审/r3-theme-checks.json)。正式程序未修改。

**用户反馈修订 R4：** 用户报告深浅主题无法连点，实际鼠标输入复现：R3 动画期间后续点击落在 HTML 根节点，按钮未收到事件；此前检查中的自动等待和脚本点击未覆盖这条路径，R3 的连点结论不足。现改为不参与交互的临时视觉层，真实按钮始终可点；保留 280ms 过渡，后续选择立即生效。桌面鼠标、390px 触摸模拟连续交替八次、键盘、导航、滚动、主题持久化和减少动画共 18 项检查通过，包含旧版失败复现，见[R4 验证](证据/2026-09-27-HTML样稿交互复审/r4-theme-pointer-checks.json)。未替代真实手机验收。

## 发现与处理

| 问题 | 对使用的影响 | 本轮候选处理 |
| --- | --- | --- |
| 流式跳过在末尾，多页又只展开两页 | 尚未看完时无法跳过，3／4 页作品不完整 | 底部阅读栏显示当前作品和页数，随时跳到下一件；完整展开全部页，最后一件不再提供无效跳过 |
| 手机导航细小，详情两侧是长条点击区 | 难点准，垂直看图时容易误碰换作品 | 导航和常用按钮加大；详情使用明确的底部前后按钮，取消边缘长条；纵向与横向手势分工 |
| 手机进入收藏缺少退出入口 | 要深入重置筛选才能回全库 | 全部／最近／收藏始终可切换；空结果提供返回全部作品 |
| 画师详情沿用图库的旧筛选 | 下一件可能跳到别的画师，返回来源丢失 | 进入详情时记录来源与作品序列，返回原画师或流式位置；Logo 单独回图库 |
| 只记滚动像素，模式切换时套旧页码 | 改变布局、切页码或重新进入后找错地方 | 按查询范围记录作品 ID、页号与页内位置；进入页码模式时重算作品所属页；普通和流式分别记忆 |
| 筛选显示灰色却代表已选，操作立即改背景 | 用户可能把想保留的画师排除，也难撤销正在调整的条件 | 明确展示每个选中项；抽屉内先调整，确认后应用，关闭取消；锁定背景并恢复焦点 |
| 收藏、搜索等小操作重建全页 | 丢输入焦点、干扰中文组合输入；键盘收藏可能误开详情 | 局部更新结果和按钮，保留输入节点，组合输入完成后检索；按键与按钮共用阅读逻辑，弹层期间隔离快捷键 |
| 画师横条只允许横向触摸 | 从缩略图开始向上滑时页面不动 | 保留横向拖动，也允许自然纵向滚动；拖动不会当作打开作品 |
| 延迟图片返回可能覆盖后来打开的页面 | 页面突然跳顶、异常或后续导航锁住 | 图片就绪后才切换；过期导航和位置恢复回调丢弃，离开页面后不再发布旧结果 |
| 设置和进度的样稿语义不一致 | 保存端口后地址立即变动；清点阶段显示假百分比 | 区分当前端口与待重启端口；清点先不报百分比，固定清单后显示处理比例，新增任务进下一轮，完成记录可回看 |

视觉上保留 Pixiv 蓝与旧版详情的上下顺序，去掉图库宣传文案和虚构的大图库统计；缩略图、标题、作者和常用操作重新分层，明暗主题共用相同结构。

## 本轮验证

- **阅读与返回：** 四页作品第 2 页跳到下一件、Logo 定位读到的作品、流式与详情往返、画师范围内连续阅读、浏览器后退、刷新恢复模式与页数。
- **输入与操作：** 收藏键盘激活、按钮之后继续用方向键、筛选取消／应用／焦点约束、日期输入不重建、倒置日期拒绝、中文组合事件模拟。
- **触摸模拟：** 画师横条内开始纵向滑动、横向拖动不误开；详情横向只换一次、纵向只滚动；流式横向不换作品；独立层双指缩放与关闭恢复。
- **状态与竞态：** 滚动切页码仍找到原作品；人为延迟图片解码后离开页面，旧结果不覆盖新页；结束任务不替换阅读节点、不改变位置；空闲隐藏进度。
- **画面：** 1440×1000、390×844、320×720，各检查深／浅主题下的图库、画师、设置和流式，共 24 种画面组合；另检查详情、抽屉、横列与放大层。
- **结果：** 最终检查未见页面异常或水平溢出；未发起外部请求。桌面放大图越界曾在验证中出现，修正后复测通过。

具体结果：[阅读](证据/2026-09-27-HTML样稿交互复审/reading-checks.json)、[桌面与任务](证据/2026-09-27-HTML样稿交互复审/desktop-checks.json)、[输入](证据/2026-09-27-HTML样稿交互复审/input-checks.json)、[触摸](证据/2026-09-27-HTML样稿交互复审/touch-checks.json)、[异步竞态](证据/2026-09-27-HTML样稿交互复审/navigation-races.json)、[画面与键盘](证据/2026-09-27-HTML样稿交互复审/layout-and-keyboard-checks.json)。

## 保留的边界

- 底部阅读栏、筛选确认方式和首尾不循环是本轮候选，仍由用户判断是否顺手；不把自审通过写成用户验收。
- 示例只有 12 件合成作品，其中 1 件默认隐藏；原图长宽差异、超长多页、动图、大型图库和资源回收仍须在正式实现中验证。
- 触摸来自 Chromium 模拟，没有替代真实手机的握持、系统手势、键盘和长时间使用验收。
- 任务与收藏仅演示本浏览器内的状态；失败、断网、重启恢复和真实 Pixiv 操作不在本轮验证范围。
- 本轮仅更新样稿、证据与三份主文档；正式源码、真实数据、配置和已有 release 未修改，BUG-053 仍阻断整版验收。
