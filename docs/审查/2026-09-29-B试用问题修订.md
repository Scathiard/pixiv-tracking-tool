## 根因与实际改动

| 问题 | 查明的原因 | 本次行为 |
| --- | --- | --- |
| 已收藏全部空心 | 把短期联网新鲜度与持久收藏事实混用；本地仍为 true，45 秒过期或重启后按钮却取消填色 | 同账号已核实的本地事实立即显示；缓存过期、离线或待核对不清空真值，新写入仍等待主站回读 |
| 流式红心延迟 | 流式页面批次没有带收藏状态，打开后另行核对才得到结果 | 按窗口批量附上本地收藏；自动核对复用同账号近 5 分钟确认结果，手动同步仍强制回读 |
| 换号与旧响应 | 旧缓存可能生成错误的取消意图，响应只有作品版本而无账号上下文 | 确认事实与当前账号分开；写请求绑定预期账号，换号失效旧上下文，重启后旧网页可以接受新的上下文；只显示一颗心 |
| 轮询持续高频 | 接收 pending 状态时重新从首次间隔排轮询 | 状态合入与下一次调度分开，保留逐步退避 |
| 设置与画师页不能滚动 | 网格内页面被内容撑到窗口外，页面自身没有滚动范围 | 限定页面高度，保留独立滚动；桌面和手机可到达底部 |
| Logo 与设置图标偏斜 | Logo 用字体和额外底部偏移；齿轮外形中心偏离画布中心 | 共用固定矢量 Logo；齿轮轮廓与内圈居中，深浅主题和手机尺寸保持一致 |
| 无缩略图一直准备中 | 没有首张原件也反复提交缩略图任务，缺文件与生成过程混为一谈 | 区分可用、未下载、失败和不可用；没有原件不提交必败任务，下载成功后的派生流程仍保留 |
| 缩略图故障挡住图库 | 缩略图提交与图库读取共用错误状态 | 缩略图失败独立反馈和重试；已经载入的卡片与后续滚动仍可使用，后台刷新失败保留当前卡片 |
| 原图临时展示 | 只使用缩略图，原图可用时也空置 | 静态卡片仅在可见区域内临时加载首张原图，离开卸载；缩略图生成后替换。动图不以大 GIF 批量兜底 |

真实服务只读抽样的前 240 件中，202 件仍保存已收藏值，其中 201 件为已确认但过期缓存，支持“显示错误而非收藏记录被清空”的判断。之前用户所见卡片短暂消失没有锁定同一根因，不能据此认定发生了删除。

当前服务曾连续记录缺首张原件的缩略图失败，另有原件请求被图片来源拒绝。没有可用原件时不能靠原图兜底解决；下载请求已带 Referer，真实拒绝原因尚未确定。本轮没有自动重试真实下载。
