状态：源码、浏览器与独立 EXE 隔离验证通过，已交付日常目录；公开版本 0.2.0，内部构建 20261003.1，真实主站、实体手机和用户体验尚未验收，未公开发布。

## 范围与基线

- 用户于本轮要求修复电脑详情底栏、将收藏放入底栏、点击后仅显示三秒实心红心再恢复查询事实、看图时点画师进全部作品、标签显示主站中文译名，以及上下方向键逐图移动。
- 主站缺中文后的本地机翻经用户选择留待以后；不引入翻译服务或模型。此前暂停的随机阅览、最后位置移除等独立需求仍保留在路线图，不计为本轮交付。
- 基线为 `main / 4c00d30d775d2f5daa2ed00271a2f06818ad8380`，公开版本 0.2.0、内部构建 20261002.1；新工作树 `.worktrees/v0.2.0-build20261003.1`，分支 `codex/v0.2.0-build20261003.1`。
- 测试只用合成图库与模拟主站，未读取或修改真实图库、配置、令牌、真实账号；不迁移 schema，不公开发布。临时结果位于仓库根 `.devtools/test-runs/b11-*`，正式脱敏证据放[同批证据](证据/2026-10-03-阅览控件与标签译名/)，保留不自动清理。

## 已复现与实现

1. **底栏：** 旧前端在 1440px 合成环境中底栏宽 330.52px、按钮宽 76.94px，“上一件／下一件”确实两行。浮动栏使用 max-content，计数的 flex-basis 与自动宽度共同挤压按钮；短中文字能换行，图标不能缩。新详情底栏用明确的四列，电脑按钮文字单行，手机改为 44px 箭头并有完整辅助标签，计数可缩，红心独占一格；移除详情正文和整理面板的重复红心。首次专项还发现底栏压到阅读画布、320px 流式画师按钮被标题截断；预留底栏空间并拆分可缩标题与独立画师按钮后，原断言和真实点击均通过。
2. **红心：** 反馈按作品及账号共享，至少三秒。快查询等到三秒结束，慢查询等到明确结论；失败／待确认恢复最后核实事实。反馈期间不显示 pending 等附加视觉，不受全局 disabled 透明度影响；不写收藏事实，不增加网络请求，不自动重复写入，辅助 pressed 状态仍为真实值。
3. **画师：** 详情身份区与流式作品标题中的画师直达其全部本地作品，清除搜索、标签、收藏、类型、日期等旧筛选，只保留排序及画师范围。路由与浏览器前后退沿用 Vue Router。
4. **逐图：** 上下通过同一页面定位函数移动一页，多页作品不用像素步长。普通阅览页首末不切作品，流式可跨作品；加载目标图片成功后才提交新位置，失败保留画面并可重试。连续输入以最新目标为准，旧请求／异步滚动恢复不能抢回；输入框、中文输入和阅读弹层不抢按键，PageUp／PageDown 沿用视口滚动。
5. **标签：** 原标签字符串仍作筛选身份，新增详情的 tag_details 展示数据，保存到现有 source_metadata.tag_translations。显式中文字段优先；App 的 translated_name 记录请求语言依据与真实字段来源，缺字段／刷新失败不清旧译名。译名变化增加目录版本，相同数据不重复增加。“刷新作品信息”复用单件 metadata 范围，不刷新画师、扫全库、重下载图片或创建媒体子任务。

## 标签来源与限制

[Pixiv 官方说明](https://www.pixiv.co.jp/news/press-release/article/10214/)说明标签译名投稿；[官方翻译规则](https://www.pixiv.help/hc/zh-tw/articles/360002987773-%E6%83%B3%E7%9F%A5%E9%81%93%E9%97%9C%E6%96%BC%E7%BF%BB%E8%AD%AF%E7%9A%84%E8%A6%8F%E5%89%87)允许中文正式名称混有英文，因此不能靠字形猜语种。

[Pixivpy 维护者源码](https://github.com/upbit/pixivpy/blob/master/pixivpy3/api.py)说明 Accept-Language 用于 tags.translated_name；这属于第三方维护者的协议证据，并非 Pixiv 官方 API 保证。[PixivFE 维护者类型](https://pkg.go.dev/codeberg.org/pixivfe/pixivfe/v3@v3.0.4/core#TagTranslations)提供 zh、zh_tw 等语言键形态。本轮没有取得实时主站字段样本：公开 HTTPS／页面读取失败，未使用真实令牌；协议解析与保存均用合成响应验证。

App 字段没有独立语言键，language_basis 明确记为 requested_locale；显式 translation.zh 或 tagTranslation[tag].zh 记为 explicit_language_key。英语字典不会被充当中文；不把主站译名称作已验证人工或机翻。旧作品此前已经丢掉译名，需要现有画师资料刷新或本轮单件刷新取回；页面读取本身不触发每次联网。
