- 只启动本次新建探针，外层分别记录开始、真实退出码、完整 stdout/stderr、时长和仪器散列；启用 faulthandler，不吞异常，不自动复跑或强杀。
- 所有输出使用新路径，已有同名目录或结果即停止。数据仍位于 D:；不读写真实图库、配置或令牌，不访问 Pixiv。
- 本目录及 11/12 轮证据保留，不自动清理。最终是否通过以完整结果和原始日志审查为准，不能仅凭退出码宣称没有原生异常。
