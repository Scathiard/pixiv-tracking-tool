# 标签排序与原图阅览

基线 `main / 12fc58fbf7b2b98e212e739cf0fa27a56cde5c3c`，原日常包 `0.2.0 / 20261021.1`。工作树 `.worktrees/v0.2.0-build20261021.2`，分支 `codex/tag-order-original-reader-20261021`。本轮按用户要求修订 R-074 和 BUG-123，不改数据库结构、配置、令牌或真实账号状态。

## 修订

- 标签来自本地 `work_tags`，同一次聚合返回对应作品数；同一作品的多页不重复计数。继续包含隐藏作品候选、排除抑制作品并附带本地已保存的官方译名。
- 默认按作品数降序，同数量按名称稳定排序；设置“界面 → 筛选标签排序”可改为名称顺序。偏好保存在当前浏览器，切换只重排已缓存候选，不重新读取或改变已选标签。
- 原闪烁有两个入口：翻页准备先取 `preview`，图片控件先显示 `preview` 再切换 `src`。两处统一直接使用最终 `src`，邻件预取复用这条路径。
- 普通详情和流式仅改变图片来源策略；原图就绪前仍保留当前件并反馈等待、取消或失败。图库卡片仍用缩略图；动图使用完整可播放文件，不将 ZIP 当图片。
- 不扩展为全库性能修复。首次标签 SQL 冷读慢仍归 BUG-122，原图未缓存时也仍可能等待。
