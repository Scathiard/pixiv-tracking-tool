# Tailscale、启动恢复与手机底栏修订

对应 R-072、BUG-115、BUG-108、BUG-116；基线 main `04dbc13`，候选 `0.2.0 / 20261017.2`。用户已要求修复后直接打包启用，仅做必要验证。最终包已在原图库正常启用；源码和浏览器检查通过，手机实体体验待用户复核。

## 改动与依据

- Tailscale：本机活动网卡返回 IPv4 `/32`，原规则只放行本机，手机 `100.95.173.87` 因而被拒绝。仅在活动 Tailscale 网卡持有对应地址时加入其 IPv4 网络范围，普通 CGNAT 网卡不会触发；原 IPv6、局域网、Host 与同源保护保留。范围依据 [Tailscale 官方地址说明](https://tailscale.com/docs/concepts/tailscale-ip-addresses)，未修改系统防火墙或登录。
- 启动：139 秒耗在查找 running 子任务。现有索引以父任务 ID 开头，旧 rowid 子查询仍扫描全部历史索引；增加全部父 ID 条件后，SQLite 可逐个查找父 ID 与状态的组合。包含已完成父任务，不丢弃中断项，不新增索引或迁移图库。见 [查询对照](证据/2026-10-17-Tailscale启动与手机底栏/startup-result.md)。
- 底栏：详情专用的 96px 网格规则覆盖手机 44px 规则，但按钮本身仍为44px，形成右侧空白并挤压计数。移除重复覆盖、统一列宽；手机将作品数和页码分为两行，上一件与下一件对齐两端，保留44px点击区；导航采用中性色，红心继续显示实际收藏状态及既有点击反馈。流式仍可点击中间区域整理作品。
