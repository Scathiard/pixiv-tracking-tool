## 目标与选择

新核心使用同一份 SQLite 主业务库，保留原画师与作品的内部 ID 和 Pixiv ID。当前三张业务表的数据通过显式版本转换映射到下表；不让导入模块、普通启动或旧探列逻辑自动转换真实库。使用 SQLAlchemy 与版本化迁移，迁移工具及应用依赖放项目环境，不安装全局依赖。

为保证旧版本可继续使用，先在隔离目录创建候选库，用旧库的一致性快照导入并核对；不直接在唯一真实数据库上试改表。隔离写入／删除／恢复测试使用合成媒体或独立复制的媒体，不能通过硬链接改到原件。

## 物理结构候选

下列为本版边界；名称为实现候选标识，不对用户界面暴露。时间统一记录明确 UTC；旧时间原值保留来源状态，不擅自补回已丢失的时区。

| 表 | 主键与关键约束 | 职责及核心字段 |
| --- | --- | --- |
| artists | id 主键；pixiv_user_id 唯一 | 身份、名称、账号、头像、加入和最近检查信息；身份删除不能级联删已存作品 |
| tracking_policies | artist_id 主键并引用 artists | mode 为 active／paused／stopped；updated_at；只决定追踪，不控制图库成员资格 |
| works | id 主键；pixiv_illust_id 唯一；artist_id 外键 | 标题、类型、预期页数、简介与获取状态、远端计数、限制等级及已知性、投稿时间与来源、首次存档时间 |
| work_tags | work_id + tag 联合主键；tag 索引 | 保留可查询 Tag 关系，不每次启动从 JSON 全量重建 |
| local_preferences | work_id 主键 | is_hidden、rating；远端刷新不得覆盖 |
| remote_bookmarks | work_id 主键 | 已知远端收藏状态、确认时间与最近错误；提交失败不得把期望值冒充远端成功；不新增离线自动收藏队列 |
| archive_intents | pixiv_illust_id 主键，不依赖作品行存在 | keep／suppressed、意图版本和更新时间；删除阻止清单即使作品记录不在也保留 |
| assets | id 主键；work_id + role + page_index 唯一 | 图片原件／动图 ZIP／时序数据，期望身份、相对路径、状态、长度、本地 SHA-256、错误与核验时间；现有路径映射保留 |
| derivatives | id 主键；work_id + kind + page_index + spec_key 唯一 | GIF／缩略图、输入资产版本、生成器版本、路径、尺寸与生成状态；失败不改变原件状态 |
| task_rounds | id 主键 | 清点／执行／结束状态、清单冻结时间、创建／结束时间、结构化结果；当前轮之外的队列单独显示 |
| operations | id 主键；round_id 可为空 | 操作种类、持久参数与范围、来源（手动／自动）、去重键、状态、阶段、结果、时间；只对活跃同意图去重 |
| operation_items | id 主键；operation_id + item_key 唯一 | 已确定处理单元、目标、单位、阶段、依赖、状态、重试次数和结果；重试不增加总量 |
| publication_journal | id 主键；operation_item_id 关联 | 发布／删除的意图版本、暂存及目标路径、执行步骤与恢复结果；恢复以实际文件和记录对账 |

数据库记录 schema revision；必要索引覆盖画师、类型、投稿时间加稳定 ID、Tag、操作状态与轮次。字段约束、外键和唯一键通过隔离测试验证，不能只靠界面约束。派生物和操作结果可由主记录推导时不另存一套不一致计数；进度接口从同一事务快照汇总。

## 旧数据逐项映射

| 旧来源 | 映射 | 必须保留的语义 |
| --- | --- | --- |
| tracked_artist.id、pixiv_user_id 及身份字段 | artists 保留内部 ID、外部 ID 和字段 | 不因改名重命名整批图片目录，不重建作品身份 |
| tracked_artist.is_active | tracking_policies：true→active，false→paused | 不能把暂停推断成 stopped；已有暂停画师仍在图库 |
| illustration.id、pixiv_illust_id、artist_id | works 保留 ID 及关系 | 现有作品 URL 和引用可兼容映射，无静默丢行 |
| 标题、类型、page_count、简介及统计字段 | works 对应字段 | 合法空简介、未获取、失败和不可用分开；既有成功数据不被空值覆盖 |
| posted_at、downloaded_at | 保存原值及 legacy 时间来源；新输入正规化 UTC | 不把已丢时区的值伪装为已知 UTC；批量远端回填另批 |
| x_restrict | 保留原值；旧数据来源不明时记录未核实 | 不凭默认 0 声称已确认全年龄，原筛选兼容差异在报告中列明 |
| illustration.tags 与 illustration_tag | 合并为去重的 work_tags；异常原值入转换报告 | 不静默丢 Tag；合法重复只合并相同关系 |
| is_hidden、rating | local_preferences | 保留用户决定，转换前后逐项对比 |
| is_bookmarked | remote_bookmarks 的旧缓存值，确认时间未知 | 保留显示，不声称刚与 Pixiv 同步；不发收藏请求 |
| file_paths | 解码并登记到 assets／derivatives，保留旧路径映射 | 先标未核验，文件非空列表不是完整性证据；越界／无法解释路径单列报告 |
| 原图片、ZIP、GIF | 不自动移动、重命名或删除；核对身份后登记角色 | GIF-only 为可阅读但缺原包；原包补下载必须用户选择 |
| 永久删除记录 | archive_intents 的 suppressed | 独立于 works 行，优先于旧任务和磁盘存在的文件 |
| gallery-dl 去重库 | 保留旧文件作为历史输入，不当新核心的完整性事实 | 不删除整个去重库来强制下载；以实际资产清单决定缺口 |
| 旧内存任务 | 无可靠可导入记录 | 升级前让现有任务结束；不能编造历史任务或声称旧闭包可恢复 |

无可解析身份的孤立文件保持原样并列入报告，不自动归属、删除或下载替代品。文件本地散列证明转换前后字节一致，不能单凭它证明与远端原作完全相同。

## 转换、激活与回退

1. **准备：** 确认实际源路径、候选路径、旧 EXE、磁盘容量和当前任务状态；停止写入并确认旧进程退出。此时生成具体影响预览，不擅自修改 .env。
2. **快照：** 使用 SQLite 一致性备份保存旧库，保存删除阻止记录和必要配置的本地保护副本；凭据不写入转换报告、日志或公开产物。原图库和旧 release 保留。
3. **候选：** 从快照向隔离候选库建表导入；媒体初步核对只读，故障测试使用独立媒体副本。所有异常与未映射项目列清单，不能带着静默丢失进入激活。
4. **核对：** 对比画师／作品 ID、关系、Tag、隐藏、评分、收藏缓存、删除阻止、旧路径与资产状态；区别登记、基础检查和深度校验三种完成程度。
5. **授权后激活：** 真实切换另行给出路径、影响、快照散列、时间与回退步骤；获得批准后由单一维护流程切换数据库、配置和运行对象。各切换点有恢复记录；激活前旧环境保持可恢复。
6. **失败恢复：** 切换前失败不碰旧环境；切换后失败先关闭候选连接，再恢复已核验的旧库／配置及旧程序。不能让新旧进程同时写同一图库。
7. **回退边界：** 新版已经产生新数据后，旧快照不包含这些变动。回退前先保存新版数据并列出差异；不静默覆盖，不承诺自动逆向转换所有新增内容。

不自动清理旧库、候选库、媒体副本、备份或 release。删除须另有明确范围和授权。

## 隔离验证与批准范围

已批准的范围：实现上述结构与转换代码，在新建的合成数据库和独立测试媒体上运行正向转换、重复执行、失败注入与恢复；不读取或转换真实图库，不修改真实 .env／令牌，不操作真实账号。

验证至少覆盖：重复 ID、无效 Tag／路径、缺页与空文件、GIF-only、时序缺失、暂停画师、已删除但目录残留、任务提交与进程重启、每个切换步骤中断、磁盘空间不足、回退后重新打开。对每项结果记录实际证据；测试通过不等于真实转换或用户验收完成。

后续真实数据操作需另列源和目标绝对路径、数据量、影响报告及可用备份，再取得相应授权。此候选本身不修改任何数据库，也不批准公开发布。
