## v0.2.0：隔离候选已交付，用户体验待验收

- 源码：`codex/v0.2.0-reading` / `a870564d0c0750b9befcb04bbb2e5d68193b4f5c`，位于 `.worktrees/v0.2.0`，继承 v0.1.2 提交；未合入 master、未推送。
- 实现：Vue 3 + TypeScript 的本地图库、普通阅览、独立流式阅览及放大层随 EXE 分发。筛选、排序、页码与连续网格并存；两种阅览位置分开保存。按钮与键盘同用导航路径，手机触控锁定方向，切换作品先准备目标图片，失败留在原处重试。
- 性能：图库按行、流式按图片页虚拟化；网格保留不超过 480 件元数据，流式保留不超过 120 页元数据，图片只在附近挂载。查询按数据库窗口取得作品和页面，固定筛选快照，旧请求不覆盖新结果；第 5000 件及图库末端已验证可达。
- 兼容：发现原包配对错误时旧 GIF 会被新版页面隐藏，已调整为继续显示可读的旧 GIF，同时保留原包错误和缺失清单。Windows 本地 HTTP 线程使用独立的 socket 事件循环，解决长时间浏览取消图片请求后服务关闭异常；不改全局 Python 设置。该循环在 Windows 上有 [512 socket 上限](https://docs.python.org/3.12/library/asyncio-platforms.html)，符合当前个人局域网服务的使用范围。
- 源码回归：最终 133 项通过，177 条既有弃用警告。首次完整回归有一项旧 GIF 显示回退，修复并新增流式断言后完整重跑通过；前端类型检查、构建及 4 项手势／导航规则检查通过。重新排版 CSS 后构建出的 JS/CSS 散列与已打包产物一致。
- 浏览器：5000 件合成图库、含 2000 页单作品，桌面和手机尺寸真实 Chromium 共 15 项通过；另有末端、第 5000 件、浏览器历史与刷新位置 5 项通过；无页面脚本错误。浏览器测试发送了真实触控事件，但没有手机实机。
- 长时间浏览：连续 30 段滚动，涵盖后台空闲和模拟下载中；屏幕图片始终 5 张、DOM 节点 157～161、页面元数据窗口 120、JS 堆 3,356,824→3,710,240 字节。连续网格 12 次滑窗保持 480 件元数据，实际渲染卡片少于 60。这里测量的是 Chromium JS 堆、节点和媒体数量，未测手机设备内存或整机资源。
- EXE：合成库里的缩略图、原图、普通／流式阅览、放大、旧设置页和手机尺寸布局共 5 项浏览器检查通过；页面无脚本错误，独立服务正常退出。打包内状态、图库、任务、页面及前端 JS/CSS 均返回 200。
- 构建：Python 3.12.13、PyInstaller 6.20.0、Node 24.15.0、npm 11.12.1、Windows 11；依赖均在项目环境。最终 EXE 74,850,402 字节，SHA-256 `8167f74e062038bb7908b28170cd8cc6f4ed9359b273289f4c8143ba59c9a21d`。
