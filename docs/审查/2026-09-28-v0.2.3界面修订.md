# v0.2.3 界面修订与交付

状态：实现、源码回归、针对性浏览器与 EXE 验证均通过，已交付到 `release/v0.2.3/` 和 `D:\PixivTracker`；当前旧版会话保留，退出旧版后打开新版即可。用户本轮要求为 R18 角标、详情收藏下移、移除收藏状态确认提示框。

## 实现与边界

- 基线为 `main` / `14dd2bb`，实现提交 `a5c7f9cec1bf140dc095c1e3fee7bb2eadf9d049`，开发分支 `codex/v0.2.3-ui-polish`。
- 同一角标控件用于图库、画师近期作品、详情和流式，现有 `x_restrict=1/2` 分别显示 R-18／R-18G，0 或未知不加标；查询字段在原批量查询中带出，没有逐件额外查询。
- 详情页主要收藏按钮放在全部图片之后、完整简介之前；虚拟化只载入一段页面时，不会误把该段末尾当成作品末尾。流式底部红心仍在跳过左侧。
- 去掉正常提交和手动同步的确认提示。正在发出请求的状态由各入口共用，按钮立即显示核对中并防重复点击；实际失败保留提示，收藏确认和离线缓存规则未改。
- 结构版本仍为 `0002_client`，v0.2.2 图库直接通用；本轮没有执行数据迁移或联网回填。只读核对真实库已有分级：普通 14,065 件，R-18 1,172 件，R-18G 7 件。
