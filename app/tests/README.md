# 测试目录约定

- `test_security.py`：网络边界、路径边界和 HTML 清洗。
- `test_jobs.py`：后台任务排队、去重、状态和错误保留。
- `test_file_index.py`：作品文件路径 JSON 编解码与单次目录扫描。
- `test_caption_state.py`：空简介、不可用作品和临时失败的状态区分。
- `test_migration.py`：数据目录预检、SQLite 快照、复制和失败回退。
- `browser_fixture.py` + `browser_smoke.py`：真实 Chromium 的桌面/手机冒烟，只使用隔离夹具，不读取真实 Pixiv token 或图库。
- `test_archive_database.py`、`test_legacy_archive_import.py`：新结构约束、旧 ID／偏好／路径映射、候选库失败回滚；只创建合成数据。
- `test_archive_media.py`、`test_archive_recovery.py`：文件解码、动图原包和时序、发布／删除中断恢复与单写入者。
- `test_archive_card_motion.py`：有界动画缩略图、短循环和总时长、GIF-only 离线生成、后台维护、源版本与发布恢复；compact 图库使用轻量缓存，详情保留原 GIF。
- `test_archive_tasks.py`、`test_archive_workflows.py`：固定轮次、真实处理量、暂停边界、精确补下载；手动全库／画师／单件范围内旧动图 ZIP／时序补齐，自动任务不顺带补旧原包；来源核对／跳过、临时失败和失败保留 GIF；HTTP 使用本机模拟服务。
- `test_archive_pipeline.py`：检查／下载／本地处理并行，逐项优先级、持久子任务、资源互斥、来源更新、真实核验计数与有界队列领取；仅合成元数据和媒体。
- `test_archive_state.py`：图库／详情／流式统一整件作品原件与处理状态；首图可读不能覆盖缺页，具体媒体请求观察缺失后更新事实；5,000 件／2,000 页批量读取。
- `test_archive_api.py`、`test_archive_pages.py`：新核心接口、旧界面适配、离线可用性、请求边界与端口反馈。
- `test_archive_relocation.py`：连续目录切换、复制被破坏和配置提交失败时保留原运行实例。
- `test_shutdown.py`、`shutdown_process.py`：托盘退出的安全收尾、排队／暂停、恢复不重做、收藏只回读和启动期间退出；独立子进程运行真实托盘回调与 Uvicorn，仅物理图标和联网部分用隔离替身，不表示实体托盘已验收。
- `test_filter_catalogue.py`：完整本地画师／标签候选、隐藏与停止追踪、空选与不限、反选标签的任意匹配，以及图库／流式／定位共用条件；只用合成图库。
- `test_archive_client_contract.py`：模拟 Pixiv 响应，验证鉴权重试、原件地址与错误结果；不访问真实账号。
- `run.py --smoke-test --smoke-output NEW_JSON_PATH`：源码与 EXE 共用的隔离冒烟，仅从本机合成图片／ZIP 服务下载，验证真实下载器、普通补下载的动图原包与两帧时序、来源不可获取后跳过并保留 GIF、原件核验、文件发布与缩略图；保留独立测试库和结果，不启动登录或托盘。
- `archive_browser.py`：新核心的桌面与手机尺寸浏览器验证；`--artifacts` 必须指定新的隔离目录，保留结果和截图；不是手机实机验收。
- `reading_browser.py`：生成大型合成图库，用实际 Chromium 验证普通／流式阅览、真实触控事件、乱序请求、长时间滚动与后台下载；`--artifacts` 每次用新目录。
- `reading_deep_browser.py`：复用前项生成的 `.devtools/test-runs/` 合成图库，验证第 5000 件作品、流式末端及浏览器返回位置；拒绝真实图库路径。
- `packaged_reading_browser.py`：让当前 EXE 只在本机启动自己的合成图库服务，验证实际下载、整件存档事实、目录版本、有界进度及图库、详情、流式、画师、设置与主题；动图卡片须使用 360×270 轻量缓存、滚动暂停和恢复，详情保留 1280×960 原 GIF；`--exe` 与 `--artifacts` 指向交付文件和新证据目录。
- `packaged_fast_scroll_browser.py`：最终 EXE 自带 3 件合成数据，浏览器克隆为 800 件元数据重放快速滚轮、一次纯文本 503 追加恢复、同 URL 静态图恢复及窗口上限；1440／390／320px，手机尺寸另用实际 CDP 触摸验证滚动，完整 800 件路径由滚轮驱动。`--exe` 必需，`--artifacts` 须为主仓库 `.devtools/test-runs/b10-packaged-fast-scroll-*` 新目录；记录 EXE 与实际供给前端的散列，不表示 800 件真实 EXE 数据库或实体手机验收。
- `test_bookmarks_v022.py`、`test_bookmark_client_v022.py`：收藏请求只写一次、同账号明确回读、旧响应、限流、未知字段、离线启动与仅回读恢复。
- `test_upgrade_v022.py`：0001 → 0002 显式转换、源库保留、未知收藏空值及失败回退；仅合成 SQLite。
- `test_v022_api.py`、`test_v022_integration.py`：统一筛选、画师资料、设置与暂停、跨模块收藏竞争及登录就绪后的恢复。
- `test_v022_scale.py`：5,000 件作品和 2,000 页单作品，检查接口窗口、批量查询和末端定位。
- `test_gallery_card_fallback.py`：合成首图缺失与可读场景，检查卡片保留、修复后派生生成及流式窗口收藏状态。
- `test_missing_media_maintenance.py`：已知缺项的自动补齐、失败记录保留、独立重试、暂停／离线、重启、去重、删除阻止及旧动图边界；仅合成图库。
- `test_request_policy.py`：HTTP／正文限流、API／图片独立冷却、服务端等待信息与准确拒绝分类；使用模拟时钟和请求，不连接 Pixiv。
- `test_processing_log.py`：隔离任务数据的只读日志、敏感字段隔离、数量上限，以及公开版本／内部构建标识；不读取真实日志或令牌。
- `test_remote_error_evidence.py`：重放合成 404、明确非公开、动图子接口、鉴权与限流回应；没有删除证据不得判删，日志保留安全原因而不输出任意远端消息。
- `test_remote_availability.py`：来源不可获取与本地存档独立、资料冲突、停止无效重试及恢复；只用合成图库。
- `client_availability_browser.py`：来源不可获取时的本地图、缺页原因、桌面／手机排版、停止轮询及任务完成后的原位恢复；只用合成图库与本机服务。
- `client_fixture.py`、`client_browser.py`：正式界面回归、5,000 / 2,000 合成图库、桌面与 390 / 320px、主题连点与收藏跨作品响应。
- `client_b_browser.py`：B 侧栏收放与锚点、手机菜单与搜索、首页检查入口、进度各状态、通知自动消失与只读日志；任务接口使用浏览器替身，`--remaining-only` 可独立复测导航与手机。
- `client_display_browser.py`：2560/1440px 设置／画师页的内容与两侧留白真实滚轮、侧栏收放，以及 390/320px CDP 触摸实际滚到底部；`--wide-only` 单独复现宽屏留白；保存图标几何与截图，不以元素存在替代可达性。
- `client_filter_browser.py`：137 位画师和逾一万项标签的完整候选、虚拟列表、搜索、勾选／反选／全选、重开回显、空结果恢复与读取失败重试；真实鼠标与 CDP 触摸覆盖桌面、390/320px，仅本机合成接口。
- `client_reader_wheel_browser.py`：2560px 下图库／详情／流式的图片与外侧留白真实滚轮，以及 390px CDP 触摸；要求全内容区能滚动。
- `client_reader_recovery_browser.py`：详情可见缺页持续轮询、同 URL 图片加载失败后自动恢复、流式存档更新事件与位置保留；使用模拟接口，无账号操作。
- `client_reader_controls_browser.py --artifacts NEW_DIRECTORY [--exe EXE_PATH]`：正式前端的 1440／390／320px 深浅主题底栏、逐图片方向键与有界窗口、目标图片失败原位重试、输入／缩放／弹层挡键、读图画师完整本地图库、主站中文标签译名和收藏点击回馈；源码使用 80 件／2,000 页合成图库，EXE 保留自带三件隔离数据，长页与故障明确为浏览器响应重放，不读取真实账号、令牌或图库。结果与失败截图写入新目录；不自动构建前端，运行前由交付流程准备生产构建。
- `client_cache_browser.py`：合成已确认收藏的首次显示、同卡片刷新和流式冷启动；缺原图与缺缩略图区分、可见原图兜底、503 后保留卡片并连续浏览 601 件；不访问真实账号。
- `client_fast_scroll_browser.py`：800 件合成图库的实际快速滚轮、生产 128 并发上限下连接／任务峰值、下一批纯文本 503 与同 URL 静态图片恢复、轻量 WebP 实际播放对照；`--recovery-suite` 加测 1440／390／320px 的持续失败预算、后台刷新、原位手动重试、离屏与后台停止；`--probe-only --media-delay-ms 500`（或 2000）仅给合成媒体增加异步响应延迟，不降低并发上限。`--artifacts` 须为主仓库 `.devtools/test-runs/b10-fast-scroll-*` 新目录，协议故障注入和受控延迟不等于复现用户服务过载。
- `client_animation_browser.py`：两帧本地 GIF 在桌面／390／320px 卡片的实际画面变化、静态回退、离屏／模拟后台释放、同地址恢复和限频；统计卡片／媒体／请求上限，不表示实体后台或超大 GIF 内存已测。
- `client_animation_performance.py`：80 件同图库的 1280×960／16 帧 GIF 与静态缩略图 AB／BA 对照，固定真实滚轮轨迹；保存浏览器进程 CPU、原始 rAF 间隔和可选解码／绘制迹线。`--frontend` 可指定已构建候选，`--media` 复用既有合成 GIF，`--preview-size 360` 仅改变供给尺寸并保持时序；`--real-derivative` 调用生产生成器并使用真实 compact API，检查无原 GIF 请求、滚动暂停、停止和返回后的实际播放。此模式生成一次同样本后用硬链接注册 80 件，任务队列生成／发布另由核心测试覆盖。`--assert-animation-budget` 令明显超出静态 CPU 预算的轮次失败。`--artifacts` 必须是主仓库 `.devtools/test-runs/b9-perf-*` 新目录；不读真实库、账号或配置，不等于 EXE／实体手机验收。
- `client_originals_browser.py`：合成缺包清单的来源与临时原因、普通补下载／显式重新核对、完成后原位移出、读取失败保留事实，以及使用主站用户 ID 的画师链接；桌面／390／320px，不执行真实账号操作。
- `client_touch_browser.py`：实际 CDP 触点、方向锁、缩放、中文输入、返回位置及无 randomUUID 环境；手机尺寸模拟不等于实机验收。
- `client_load_browser.py`：故障图片重试、第 5,000 件定位、下载中的长流阅览、固定总量与下一轮、部分失败记录、暂停队列和离线浏览。
- `client_pipeline_browser.py`：已构建正式前端与内存合成接口，桌面／390／320px 验证并行进度、版本原位更新、整件作品状态、实际图片加载、位置和收藏请求；不读取后端、账号或真实图库。
- 上述 client 脚本均要求新的 `--artifacts` 目录，保留模拟媒体、结果和失败截图；只使用合成账号，禁止传入真实图库。
- `run.py --smoke-test --smoke-serve-port PORT --smoke-stop-file FILE`：仅隔离验证用，监听 `127.0.0.1`，最多运行 180 秒；普通启动不进入此入口。
- 没有 `py` 启动器时可使用 `.devtools/v012-env/Scripts/python.exe`（Python 3.12）；指定 `.devtools/test-runs/` 下新的 `--basetemp`，不得重复使用会清理旧证据的路径。
- 每个测试自行创建临时目录；不得依赖或修改项目 `.env`、`data/`、`images/` 和 `release/`。
