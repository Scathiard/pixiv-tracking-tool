# 本地阅览前端

`src/` 保存 Vue 3 + TypeScript 界面、状态与样式，`tests/` 验证导航和手势规则；`dist/` 为随 EXE 打包的产物，`node_modules/` 为项目依赖，均不进入源码提交。构建使用新的输出目录，不自动删除旧证据或 release。

图库按行虚拟化；普通阅览与流式阅览按图片页虚拟化，最多保留 120 页元数据窗口。向前或向后滑动窗口时用作品 ID、页号和像素偏移保持画面位置，窗口不限制可遍历的图库范围。图片组件离开窗口就释放引用，缩略图不能回退到大原图。

界面保留深色背景和蓝色操作色：背景 `#101216`、面板 `#191d24`、分隔 `#303642`、正文 `#e6eaf1`、次要文字 `#a1acbc`、操作 `#8fbcff`。标题使用本机 Segoe UI Variable／微软雅黑，正文微软雅黑／系统字体，页号用 Cascadia Mono／等宽字体，不请求在线字体。

图片是主体；主要控件放在短导航栏和底部阅读工具条，信息侧栏可收起。普通阅读提供前后作品，流式阅读提供跳过当前作品；两种模式分开保存位置。过渡仅用于作品切换，尊重减少动态效果设置。

开发：`npm ci`，`npm run check`，`npm test`；`npm run build -- --outDir <新的产物目录>`。正式构建入口同时读取前端产物，见 `app/build.spec`。
