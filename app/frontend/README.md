# 本地阅览前端

`src/` 是 Vue 3 + TypeScript 界面；`components/` 放共用控件，`views/` 放画师与设置页面，`state/` 放跨页面的收藏状态。`tests/` 验证导航手势和收藏版本规则。`dist/` 是打包产物，`node_modules/` 是项目局部依赖，不提交。

R4 界面使用本机字体和本地图片，包含图库范围与筛选、作品详情与完整简介、流式阅览、画师管理、设置和任务日志。Vue Router 4 管理页面 URL。图库连续模式最多保留 480 件元数据；详情与流式阅览最多保留 120 页元数据。新进图库、流式及指定作品仍从开头读，不保存最后停留位置；同次缩放、窗口变化及后台修复保留当前位置。

收藏图标从后端确认状态绘制；点击后以实心红心作至少三秒的临时反馈，待查询有结论后恢复核实事实，临时颜色不写入收藏状态。失败、待确认与旧缓存分别标记。详情与流式焦点会限速核对，手动同步可在作品整理面板执行。

详情的收藏按钮放在固定底栏；上下方向键逐图片页移动，左右切作品。看图时点画师打开其全部本地作品，清除其他筛选并保留排序。作品标签在原名旁灰色显示已存的 Pixiv 中文译名，缺译名保留原名；“刷新作品信息”只取当前作品资料，不重下载图片，译名随后可离线显示。没有自行翻译或其他翻译网站调用。

开发命令：`npm ci`、`npm run check`、`npm test`、`npm run build`。浏览器交互和 EXE 验证需分别记录。

## 游标读取与按需操作

普通首屏、连续图库滚动、普通阅览相邻作品及顺序流式使用代际绑定的游标，固定窗口定位作品与图片页。图库仍最多保留 480 件卡片，图片窗口最多 120 页，顺序读取的定位缓存最多 240 页。图库发生变更导致游标过期时，保留已显示内容并提供“重新定位后继续”，重新定位会整窗替换，不能混入旧代际的卡片或页。

常用全库、单画师、单类型和收藏范围的数量来自维护好的投影。搜索、复杂筛选与自定义旧上界保留原语义，但不自动扫描其精确数量；点击“统计数量”才计算精确数量和侧栏统计。数字页码跳转继续可用，并明确提示目标页之前的读取成本。随机流式继续冻结当前阅读范围、按作品洗牌及跨轮返回；选择随机时明确说明按需读取范围的成本。

历史版本菜单初次只取最近 100 个版本及当前选择的旧版本，点击“加载更早版本”可逐批取完完整历史。

`tests/cursor-gallery-browser.py --artifacts NEW_DIRECTORY` 提供正式构建与真实隔离 Runtime 的桌面／390／320px 冒烟：61 件合成作品含一件 200 页作品。运行前先构建前端；不能传入真实图库或账号。当前云环境对独立 Chromium 的本地配置 socket 及跨工具 localhost 访问有隔离限制，API／逻辑测试通过不代表此浏览器体验已经验证。
