# 本地阅览前端

`src/` 是 Vue 3 + TypeScript 界面；`components/` 放共用控件，`views/` 放画师与设置页面，`state/` 放跨页面的收藏状态。`tests/` 验证导航手势和收藏版本规则。`dist/` 是打包产物，`node_modules/` 是项目局部依赖，不提交。

R4 界面使用本机字体和本地图片，包含图库范围与筛选、作品详情与完整简介、流式阅览、画师管理、设置和任务历史。Vue Router 4 管理页面 URL。图库连续模式最多保留 480 件元数据；详情与流式阅览最多保留 120 页元数据。位置按筛选范围与模式分别保存，并用作品 ID 恢复。

收藏图标从后端确认状态绘制；提交时保留旧颜色，等待操作回读。失败、待确认与旧缓存分别标记。详情与流式焦点会限速核对，手动同步可在作品整理面板执行。

开发命令：`npm ci`、`npm run check`、`npm test`、`npm run build`。浏览器交互和 EXE 验证需分别记录。
